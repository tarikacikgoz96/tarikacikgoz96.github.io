ABAP Itab to Excel (Background, Not OLE)

Published: 08.07.2026 Updated: 08.07.2026

Bir abap programındaki itab’ı Excel dosyasına (.xlsx) OLE kullanmadan ve arkaplanda aktarımını sağlar.

Bu metot SAP’ın ALV toolbarındaki Excel dönüşüm işlemleri (SAP’ın orjinal kodları) debug edilerek oluşturulmuştur. Tam verimle çalışmaktadır. Arka planda dönüştürüp, OLE’deki gibi Excel’in bilgisayarda açılmasına gerek duymamaktadır.

Bilinmesi gerekenler:

  • .xls değil, .xlsx ile çalışılır (Modern Excel).
  • Alan adları ile dışa aktarırsanız, içeri aktarımda uygun kolonlara otomatik aktarım sağlanır. (Tip uyumlu aktarım)

Uygulama:

  • Itab’ı ve dosya yolunu metoda verin (C:\Users\UserName\Desktop\export.xlsx)
  • Sütun adları seçeneklerini seçin (itab fnames, data element names, custom colnames, etc.)
  • Çalıştırın.

“Excel to Itab” için buraya tıklayınız: ABAP Excel to Itab (Background, No OLE)

Temel çalıştırma aşağıdaki gibidir;

REPORT ZTEMPLATE_XLSX_OUT.

TABLES: mara.

DATA: lo_cls TYPE REF TO zcl_template,
      lv_message TYPE string,
      gt_mara TYPE TABLE OF MARA. "itab

SELECT-OPTIONS: s_MATNR FOR MARA-MATNR.
PARAMETERS: p_path TYPE char260.
"windows path uzunluğu maksimium 260 dır.

START-OF-SELECTION.


CREATE OBJECT lo_cls.

PERFORM get_data.

lo_cls->itab_to_excel(
  EXPORTING
    iv_path            = p_path
*    iv_colname_type    = 'F'    " D: Data element, F: Field name
*    iv_add_fname       = 'X'    " Sütun adları sonuna fname ekle (D yada Custom ise)
*    iv_fname_seperator = '-'
*    it_custom_colnames =     " if suplied direkt custom yap
*    it_hide_columns    =     " No send to XLSX this columns
  IMPORTING
    ev_message         = lv_message
  CHANGING
    it_itab            = gt_mara
).

MESSAGE lv_message TYPE 'S'.

end-of-SELECTION.

FORM GET_DATA.
  SELECT *
    FROM MARA
    INTO TABLE GT_MARA
    WHERE MATNR IN S_MATNR.
ENDFORM.

ITAB_TO_EXCEL metodu;

*Method Signature:
*IV_PATH            TYPE CHAR260	
*IV_COLNAME_TYPE    TYPE CHAR1  DEFAULT 'F'	D: Data element, F: Field name
*IV_ADD_FNAME       TYPE FLAG   DEFAULT 'X'	Sütun adları sonuna fname ekle (D yada Custom ise)
*IV_FNAME_SEPERATOR TYPE CHAR1  DEFAULT '-'	
*IT_CUSTOM_COLNAMES TYPE WDY_KEY_VALUE_LIST OPTIONAL	if suplied direkt custom yap
*IT_HIDE_COLUMNS    TYPE SOLI_TAB OPTIONAL	No send to XLSX this columns
*EV_MESSAGE         TYPE STRING	
*IT_ITAB            TYPE TABLE	

  method ITAB_TO_EXCEL.

    ev_message = 'OK'.
    data: lv_xstring      TYPE xstring,
          lv_xml_stream   TYPE XML_RAWDATA,
          lv_length       type i,
          lv_colname_type TYPE char1,
          ls_ccolname TYPE wdy_key_value,
          lr_itab TYPE REF TO data.
    TRY.
        cl_salv_table=>factory(
          IMPORTING r_salv_table = DATA(lo_table)
          CHANGING  t_table      = it_itab ).

        DATA(lt_fcat) =
          cl_salv_controller_metadata=>get_lvc_fieldcatalog(
            r_columns      = lo_table->get_columns( )
            r_aggregations = lo_table->get_aggregations( ) ).

        delete lt_fcat WHERE fieldname eq 'MANDT'.
        "--------
        "hide columns
        LOOP AT it_hide_columns ASSIGNING FIELD-SYMBOL(<fs_hide>).
          delete lt_fcat where fieldname eq <fs_hide>-line.
        ENDLOOP.
        "--------
        "colnames
        FIELD-SYMBOLS: <fs_fcat> like LINE OF lt_fcat.
        lv_colname_type = iv_colname_type.
        IF it_custom_colnames is SUPPLIED.
          lv_colname_type = 'C'.
        ENDIF.
        CASE lv_colname_type.
          WHEN 'C'."custom
            LOOP AT lt_fcat ASSIGNING <fs_fcat>.
              clear ls_ccolname.
              READ TABLE it_custom_colnames INTO ls_ccolname
              WITH key key = <fs_fcat>-fieldname.
              IF sy-subrc eq 0.
                <fs_fcat>-reptext = ls_ccolname-value.
              ENDIF.
            ENDLOOP.
          WHEN 'D'."data element
            "continue...
          WHEN 'F'."field name
            LOOP AT lt_fcat ASSIGNING <fs_fcat>.
              <fs_fcat>-reptext = <fs_fcat>-fieldname.
            ENDLOOP.
        ENDCASE.
        IF iv_add_fname eq 'X'.
          IF lv_colname_type eq 'C' or lv_colname_type eq 'D'.
            LOOP AT lt_fcat ASSIGNING <fs_fcat>.
              <fs_fcat>-reptext = <fs_fcat>-reptext
              && iv_fname_seperator && <fs_fcat>-fieldname.
            ENDLOOP.
          ENDIF.
        ENDIF.
        "--------


        GET REFERENCE OF it_itab INTO lr_itab.

        DATA(lo_result) =
          cl_salv_ex_util=>factory_result_data_table(
            r_data         = lr_itab"DATA REFESANS İSTİYOR
            t_fieldcatalog = lt_fcat ).

        cl_salv_bs_tt_util=>if_salv_bs_tt_util~transform(
          EXPORTING
            xml_type      = if_salv_bs_xml=>c_type_xlsx
            xml_version   = cl_salv_bs_a_xml_base=>get_version( )
            r_result_data = lo_result
            xml_flavour   = if_salv_bs_c_tt=>c_tt_xml_flavour_export
            gui_type      = if_salv_bs_xml=>c_gui_type_gui
          IMPORTING
            xml           = lv_xstring ).


        CALL FUNCTION 'SCMS_XSTRING_TO_BINARY'
          EXPORTING
            buffer        = lv_xstring
          IMPORTING
            output_length = lv_length
          TABLES
            binary_tab    = lv_xml_stream.


        data lv_path TYPE string.
        lv_path = iv_path.
        CALL METHOD cl_gui_frontend_services=>gui_download
          EXPORTING
            bin_filesize = lv_length
            filetype     = 'BIN'
            filename     = lv_path
          CHANGING
            data_tab     = lv_xml_stream
          EXCEPTIONS
            OTHERS       = 1.
        IF sy-subrc <> 0.
*           MESSAGE ID SY-MSGID TYPE SY-MSGTY NUMBER SY-MSGNO
*                      WITH SY-MSGV1 SY-MSGV2 SY-MSGV3 SY-MSGV4.
        ENDIF.

    CATCH cx_root.
        CLEAR lv_xstring.
        ev_message = 'NOK'.
        RETURN.
    ENDTRY.


  endmethod.
