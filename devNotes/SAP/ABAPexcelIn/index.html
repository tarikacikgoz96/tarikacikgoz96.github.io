ABAP Excel to Itab (Background, Not OLE)

Published: 08.07.2026 Updated: 08.07.2026

Bir Excel dosyasının (.xlsx) içeriğini OLE kullanmadan ve arkaplanda itab’a aktarımını sağlar.

Bu metot SAP’ın ALV toolbarındaki Excel dönüşüm işlemleri (SAP’ın orjinal kodları) debug edilerek oluşturulmuştur. Tam verimle çalışmaktadır. Arka planda dönüştürüp, OLE’deki gibi Excel’in bilgisayarda açılmasına gerek duymamaktadır.

Itab’ın içeriğinde veri varsa, Excel içeriğini ona append eder.
Tip dönüşlümlerini Itab’ın alan adlarına göre uygular.

Uygulama:

  • Itab’ı ve dosya yolunu metoda verin (C:\Users\UserName\Desktop\export.xlsx)
  • Çalıştırın.

“Itab to Excel” için buraya tıklayınız;ABAP Itab to Excel (Background, No OLE)

Temel çalıştırma aşağıdaki gibidir;

REPORT ZTEMPLATE_XLSX_IN.

TABLES: mara.

DATA: lo_cls TYPE REF TO zcl_template,
      lv_message TYPE string,
      gt_mara TYPE TABLE OF MARA. "itab

SELECT-OPTIONS: s_MATNR FOR MARA-MATNR.
PARAMETERS: p_path TYPE char260.
"windows path uzunluğu maksimium 260 dır.

START-OF-SELECTION.


CREATE OBJECT lo_cls.

PERFORM get_data.


lo_cls->excel_to_itab(
  EXPORTING
    iv_path    = p_path
*    iv_field_seperator = '-'
  IMPORTING
    et_itab    = gt_mara
    ev_message = lv_message
).

MESSAGE lv_message TYPE 'S'.

BREAK-POINT.

end-of-SELECTION.

FORM GET_DATA.
  SELECT *
    FROM MARA
    INTO TABLE GT_MARA
    WHERE MATNR IN S_MATNR.
ENDFORM.

EXCEL_TO_ITAB metodu;

*Method Signature:
*IV_PATH	        TYPE CHAR260
*IV_FNAME_SEPERATOR	TYPE CHAR1  DEFAULT '-'
*ET_ITAB	        TYPE TABLE
*EV_MESSAGE	        TYPE STRING

  METHOD excel_to_itab.

    ev_message = 'OK'.
    DATA: lv_filename TYPE string,
          lt_content  TYPE TABLE OF indx_clust,
          ls_content  TYPE indx_clust,
          lv_streamx  TYPE xstring,
          lr_xlsx     TYPE REF TO data.

    FIELD-SYMBOLS : <ft_xlsx> TYPE STANDARD TABLE,
                    <fs_xlsx> TYPE any,
                    <fv_xlsx> TYPE any.

    FIELD-SYMBOLS : <ft_itab> TYPE ANY TABLE,
                    <fs_itab> TYPE any,
                    <fv_itab> TYPE any.


    DATA: tabledescr1    TYPE REF TO cl_abap_tabledescr,
          descr1         TYPE REF TO cl_abap_structdescr,
          lt_itab_fields TYPE TABLE OF abap_compdescr.
    FIELD-SYMBOLS: <fs_itab_fields> LIKE LINE OF lt_itab_fields.


    DATA: tabledescr2    TYPE REF TO cl_abap_tabledescr,
          descr2         TYPE REF TO cl_abap_structdescr,
          lt_xlsx_fields TYPE TABLE OF abap_compdescr,
          ls_xlsx_fields TYPE abap_compdescr.


    ASSIGN et_itab TO <ft_itab>.

    DATA lrs_itab TYPE REF TO data.
    CREATE DATA lrs_itab LIKE LINE OF <ft_itab>.
    ASSIGN lrs_itab->* TO <fs_itab>.

    DATA field_ind TYPE i.

    TRY .
        "1-binary şekilde dosyayı okuyoruz.
        lv_filename = iv_path.
        cl_gui_frontend_services=>gui_upload(
              EXPORTING
                filename = lv_filename
                filetype = 'BIN'
              CHANGING  data_tab = lt_content
          ).


        "2-binary'i xstring'e dönüştürüyoruz.
        LOOP AT lt_content INTO ls_content.
          CONCATENATE lv_streamx ls_content INTO lv_streamx IN BYTE MODE.
        ENDLOOP.

        "3-xstring'ten xml obje oluşturuyoruz.
        DATA(lo_xlsx) = NEW cl_fdt_xl_spreadsheet( document_name = 'ITAB_XLSX'
                                                  xdocument     = lv_streamx ).
        CLEAR lv_streamx.
        FREE  lv_streamx.

        "Get xlsx sheets
        lo_xlsx->if_fdt_doc_spreadsheet~get_worksheet_names(
          IMPORTING
            worksheet_names = DATA(lt_sheets)
        ).



        "4-xml'den de veriyi itab'a çekiyoruz.
        READ TABLE lt_sheets INTO DATA(ls_sheet) INDEX 1."yalnızca ilk sheet okunur.
        lr_xlsx = lo_xlsx->if_fdt_doc_spreadsheet~get_itab_from_worksheet( ls_sheet ) .
        FREE lo_xlsx.
        ASSIGN lr_xlsx->* TO  <ft_xlsx>.


        tabledescr1 ?= cl_abap_typedescr=>describe_by_data( <ft_itab> ).
        descr1 ?= tabledescr1->get_table_line_type( ).
        MOVE descr1->components TO lt_itab_fields.


        tabledescr2 ?= cl_abap_typedescr=>describe_by_data( <ft_xlsx> ).
        descr2 ?= tabledescr2->get_table_line_type( ).
        MOVE descr2->components TO lt_xlsx_fields.

        "bu kısım xlsx alanlarını itab ile uygun olanlar ile eşler.
        "--------------------------
        "xlsx alanalrının gerçek alan adlarını ilk satırdan öğrenme.
        "transpoze
        READ TABLE <ft_xlsx> ASSIGNING <fs_xlsx> INDEX 1.

        DATA: lt_xlsx_realfn TYPE wdy_key_value_list,
              ls_xlsx_realfn LIKE LINE OF lt_xlsx_realfn.

        DATA: lv_first  TYPE string,
              lv_second TYPE string.

        LOOP AT lt_xlsx_fields INTO DATA(ls_field).
          CLEAR: lv_first, lv_second, ls_xlsx_realfn.
          ASSIGN COMPONENT ls_field-name
                 OF STRUCTURE <fs_xlsx>
                 TO <fv_xlsx>.
          ls_xlsx_realfn-key = ls_field-name.

          IF CONV string( <fv_xlsx> ) CS iv_fname_seperator.
            "seperator içeriyorsa ayır ve ikincisini ekle.
            SPLIT CONV string( <fv_xlsx> ) AT iv_fname_seperator
                  INTO lv_first lv_second.
            "içermiyor ise doğrudan alan adı kabul et.
            ls_xlsx_realfn-value = lv_second.
          ELSE.
            ls_xlsx_realfn-value = <fv_xlsx>.
          ENDIF.

          APPEND ls_xlsx_realfn TO lt_xlsx_realfn.

        ENDLOOP.


        LOOP AT <ft_xlsx> ASSIGNING <fs_xlsx> FROM 2.
          CLEAR <fs_itab>.
          LOOP AT lt_itab_fields ASSIGNING <fs_itab_fields>.
            IF <fs_itab_fields>-type_kind EQ 'R' OR
                <fs_itab_fields>-type_kind EQ 'H' OR
                <fs_itab_fields>-name EQ 'MANDT' .
              "tablo (H) yada class (R) ise atla.***
              CONTINUE.
            ELSE.
              "xlsx deki alan karşılığını bul.
              READ TABLE lt_xlsx_realfn INTO ls_xlsx_realfn
              WITH KEY value = <fs_itab_fields>-name.
              IF sy-subrc EQ 0.
                READ TABLE lt_xlsx_fields INTO ls_xlsx_fields
                WITH KEY name = ls_xlsx_realfn-key.
                IF sy-subrc EQ 0.
                  ASSIGN COMPONENT ls_xlsx_fields-name OF STRUCTURE <fs_xlsx> TO <fv_xlsx>.
                  ASSIGN COMPONENT <fs_itab_fields>-name OF STRUCTURE <fs_itab> TO <fv_itab>.
                  IF <fs_itab_fields>-type_kind = 'D'.
                    TRANSLATE <fv_xlsx> USING '- . / '.
                    CONDENSE  <fv_xlsx> NO-GAPS.
                  ENDIF.
                  <fv_itab> = <fv_xlsx>.


                  UNASSIGN <fv_xlsx>.
                  UNASSIGN <fv_itab>.
                ENDIF.
              ENDIF.

            ENDIF.
          ENDLOOP.
          INSERT <fs_itab> INTO TABLE <ft_itab>.
        ENDLOOP.
        "--------------------------




        "bu kısım xlsx'yi itab'a xlsx'in sütun sırasına göre sırayla işler.
        "--------------------------
*      LOOP AT <ft_xlsx> ASSIGNING <fs_xlsx> FROM 2."İlk satır fnames
*        CLEAR <fs_itab>.
*        field_ind = 1.
*        LOOP AT lt_itab_fields ASSIGNING <fs_itab_fields>.
*          IF <fs_itab_fields>-type_kind EQ 'R' OR
*             <fs_itab_fields>-type_kind EQ 'H' OR
*             <fs_itab_fields>-name EQ 'MANDT' .
*            "tablo (H) yada class (R) ise atla.***
*            CONTINUE.
*          ELSE.
*            READ TABLE lt_xlsx_fields INTO ls_xlsx_fields INDEX field_ind.
*            ASSIGN COMPONENT ls_xlsx_fields-name OF STRUCTURE <fs_xlsx> TO <fv_xlsx>.
*            ASSIGN COMPONENT <fs_itab_fields>-name OF STRUCTURE <fs_itab> TO <fv_itab>.
*            IF <fs_itab_fields>-type_kind = 'D'.
*              TRANSLATE <fv_xlsx> USING '- . / '.
*              CONDENSE  <fv_xlsx> NO-GAPS.
*            ENDIF.
*            <fv_itab> = <fv_xlsx>.
*
*
*            UNASSIGN <fv_xlsx>.
*            UNASSIGN <fv_itab>.
*            field_ind = field_ind + 1.
*          ENDIF.
*        ENDLOOP.
*        insert <fs_itab> into TABLE <ft_itab>.
*      ENDLOOP.
        "--------------------------

      CATCH cx_root.
        ev_message = 'NOK'.
    ENDTRY.



  ENDMETHOD.
