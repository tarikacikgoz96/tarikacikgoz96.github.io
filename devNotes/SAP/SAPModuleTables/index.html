SAP Development General Module Tables

Published: 03.11.2026 Updated: 03.11.2026

Kariyerimde geliştirmelerde karşılaştığım ve yine SAP geliştiricilerinin sıkça kullandığı temel tabloların kısa tanıtımıdır.

FI

Muhasebe ana modülü. Gelir gider faturalarının girilmesi, hesaplara atanması
Sadece FI da olan faturalar olduğu gibi, SD ve MM faturalarının da FI’ya dönüşmüş halleri bulunur.

  • SKA1 : Ana hesap ana verileri (hesap planı bazında)
  • SKB1 : Ana hesap ana verileri (şirket kodu bazında)
  • BKPF : Muhasebe belgesi başlık bilgileri (FI faturası)
  • BSEG : Muhasebe belgesi kalem bilgileri (FI faturası)
  • ACDOCA : FI ve CO kayılarının birleşik tutulması. Muhasebe belgesi kalem bazında HANA
    (Fatura-kalem-masraf yeri-masraf çeşidi)
  • T001 : Şirket kodları

MM

Malzeme yönetim modülüdür.
Dışardan alınan ve üretilen malzemelerin kayıtları tutulur.
Satın Alma Talebi -> Satın Alma Siparişi -> Mal Girişi -> MM Faturası

  • MARA : Genel malzeme ana verileri, malzeme tanımlama
  • MAKT : Malzeme açıklamaları
  • MARC : Malzeme - Üretim yeri
  • MARD : Malzeme - depo - miktar bilgisi
  • EBAN : Satın alma talebi başlıkları (SAT)
  • EBKN : Satın alma talebi kalemleri (SAT)
  • EKKO : Satın alma belgesi başlıkları (SAS)
  • EKPO : Satın alma belgesi kalemleri (SAS)
  • EKKN : Satınalma belgesinde hesap tayini (SAS)
  • EKBE : SAS kalem faturaları geçmişi (SAS)
  • MKPF : Malzeme belgesi başlıkları (Mal girişi)
  • MSEG : Malzeme belgesi kalemleri (Mal girişi)
  • MATDOC : Malzeme hareketleri HANA (Depo-miktar vb.)
  • RBKP : Malzeme satın alma faturası (MM Faturası)
  • RSEG : Malzeme satın alma fatura kalemi (MM Faturası)
  • LFA1 : Satıcı ana verileri (Supplier)
  • LFB1 : Satıcı ana verileri (şirket kodu bazında)

PP

Malzemelerden ürün oluşturulur, buna ürün ağacı(BOM) denir.

  • MAST : Malzeme - BOM bağlantısı
  • STKO : BOM başlığı
  • STPO : BOM kalemleri
  • AFKO : Üretim emri başlığı
  • AFPO : Üretim emri kalemleri

SD

Dışarıya sattığımız ürünlerin modülüdür.
Sipariş -> Teslimat -> Faturalama şeklinde bir akış vardır.

  • KNA1 : Müşteri ana verileri (Customer)
  • KNB1 :Müşteri ana verileri (şirket kodu bazında)
  • VBAK : Satış siparişi belgesi: Başlık verileri
  • VBAP : Satış siparişi belgesi: Kalem verileri
  • LIKP : Teslimat belgesi: Başlık verileri
  • LIPS : Teslimat belgesi: Kalem verileri
  • VBRK : Satış Faturalama: Başlık verileri (SD faturası)
  • VBRP : Satış Faturalama: Kalem verileri (SD faturası)
  • KONV : Satış Faturalama: Belge Koşulları (İndirim, KDV vb.)
  • PRCD_ELEMENTS : KONV’nin HANA versiyonu
  • VBFA : Satış belge akışı-bağlantıları

CO

Maliyet muhasebesidir. Hangi alanda (masraf yeri, masraf çeşidi, hesap planı) ne kadar harcama yapıldı vb.

  • CSKS : Masraf yerleri (KOKRS-KOSTL-DATBI)
  • CSKT : Masraf yerleri detay
  • CSKA : Masraf çeşitleri (KTOPL-KSTAR)
  • CSKB : Masraf çeşitleri kontrol tablosu (KOKRS-KSTAR-DATBI)
  • SKA1 : G/L hesap no bilgileri (KTOPL-SAKNR)
  • SKB1 : G/L hesap no bilgileri (BUKRS-SAKNR)
  • COSP : Masraf toplamı (Harcamalar)
  • FAGLFLEXT : Defteri Kebir: Toplamlar (COSP yerine, Masraf yeri-Hesap bazında harcama yıllık-aylık)
  • T004 : Hesap planları (KTOPL)
  • TKA02 : KOKRS-BUKRS ataması
    (KOKRS-BUKRS: kontrol ve şirket kodu, KSTAR-SAKNR: masraf çeşidi/hesap no,
    KTOPL: hesap planı, KOSTL: masraf yeri, RLDNR: defter)

LO-VC

Malzemenin-ürünün özelliklerinin belirtilmesi.
Sınıf -> Karakteristik -> Değer ilişkisi vardır.

  • KLAH : Sınıf ana verileri
  • KSML : Sınıf – karakteristik bağlantısı
  • CABN : Karakteristik ana verileri
  • CABNT : Karakteristik açıklamaları
  • CAWN : Karakteristik değerleri
  • CAWNT : Karakteristik değer açıklamaları
  • AUSP : Nesnelere atanmış karakteristik değerleri
